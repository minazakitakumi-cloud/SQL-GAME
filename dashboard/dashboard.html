    PLAYER HANDBOOK

    SQL Quest Game Guide

    A friendly walkthrough of challenge mode, points, hints, and practice.

    Getting started Points & hints Practice mode
    01

    Start a scored game

    1. Choose a difficulty on the dashboard, then select Start game.
    2. Read the task and inspect the table name, column names, data types, and sample rows.
    3. Write a read-only SQL query in the editor and select Check answer.
    4. Use Run SQL to preview your query against the challenge sample data without submitting it. Check your answer when you are ready.

    Press Tab in the SQL editor to insert indentation. Use Clear if you want to rewrite your query.

    02

    Pick the right challenge

    • Easy: a single table, a basic SELECT, and one WHERE filter.
    • Medium: filtering with sorting, or a simple aggregate.
    • Hard: GROUP BY with HAVING, or a meaningful aggregate query.
    03

    Points, hints, and lives

    • A correct answer earns 10 points on Easy, 25 on Medium, or 50 on Hard.
    • Your total points are saved to your signed-in account. The dashboard and game show that permanent balance.
    • Each scored question has three progressive hints. Their costs are 3, 5, and 7 points, in order.
    • You need enough points for the full hint cost. Once unlocked, you can revisit a hint without paying again.
    • You start with 3 lives. An incorrect answer costs one life; the question still completes and the game moves on.

    The in-game score is for the current run. Total points are your persistent account balance; starting another run does not reset that balance.

    04

    Review your answers

    Open dashboard View History to review every scored game session and practice session, including questions, table data, submitted SQL, and feedback. Signed-in sessions are saved to your account.

    05

    Practice without scoring

    Choose Practice SQL to enter any SQL topic you want to work on. Each exercise comes with its own question, tables, sample data, and up to five free progressive hints.

    Practice answers do not award or deduct points and do not cost lives. Use Run SQL to preview a read-only query against the sample data, then check your answer when you are ready. Practice sessions appear in dashboard View History when you are signed in.

    06

    Leaderboard & SQL Assistant

    The leaderboard ranks accounts with positive permanent point balances; tied scores share a rank. Refresh it to request current results.

    Open Chat to ask the SQL Assistant about SQL concepts and query structure. It can explain an idea, but your game answer still needs to solve the displayed challenge.
